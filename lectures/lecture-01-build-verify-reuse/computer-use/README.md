# Computer Use · Prepare promotion drafts

Use a task brief and three reference documents to prepare LinkedIn, INFORMS Connect, and Outlook drafts for Service Science Online Forum Episode 14. Practice checking facts, destinations, and the final on-screen result.

## Before you start

Copy this folder to your own working location. Use an agent that can read Word documents, browse the web, edit files, and operate the relevant apps. The supplied assignment describes the instructor's demonstration accounts and destinations. For your own live exercise, update the assignment to the accounts and destinations you intend to use, and make those signed-in sessions available.

## What to do

1. Read [assignment.md](assignment.md) and the three documents in [templates/](templates/README.md).
2. Open this folder as your agent's working folder and give it the prompt below.
3. Review the updated documents against the event source, then inspect the prepared app drafts and recipient fields.
4. Keep the original documents and the revised copies so you can compare the results.

> Follow assignment.md. Read the three Word reference documents in templates/, preserve the originals, and prepare updated copies for the selected event. Verify the event facts and links against the source. Use the specified apps to fill the requested drafts, inspect them, and leave them available for my review. Report the output files, draft locations, and any incomplete steps. Stop before Post or Send.

## Expected result

Three updated documents, one LinkedIn group draft, a draft for each of the four specified INFORMS communities, and one Outlook email draft. Identify whether each app result is saved, remains in an open composer, or is blocked. Review the text locally if an app cannot retain multiple drafts at once.

The exercise ends at review; the original assignment deliberately leaves Post and Send to the human reviewer.
