# Current assignment inputs

Use this folder for the live assignment, not for the fixed failure exercise.

| File | Purpose |
|---|---|
| [assignment.md](assignment.md) | Select the episode, speaker, event source, destinations, and email routing here. |
| [linkedin.docx](linkedin.docx) | Reference LinkedIn style and structure. |
| [informs.docx](informs.docx) | Reference INFORMS Connect announcement style and structure. |
| [email.docx](email.docx) | Reference email invitation style and structure. |
| [README.md](README.md) | Explain input roles and how to select a new event. |

To reuse the workflow, update assignment.md for the next event and replace templates only if the desired channel style changes. Verify all current facts from the selected event source; historical template facts are not defaults. If the source is unavailable, add verified facts and their source/date to assignment.md. The agent reads these inputs afresh each run and leaves them unchanged during execution.

The three templates start with the same content as the Computer Use templates so either exercise can be used independently.
