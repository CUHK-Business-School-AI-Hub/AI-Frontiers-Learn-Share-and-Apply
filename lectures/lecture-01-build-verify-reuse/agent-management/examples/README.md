# Fixed failure exercise

These are authored teaching examples with intentional errors, not real agent results. Use the saved facts in case-brief.md even if the current assignment selects another event.

| File | Purpose / action |
|---|---|
| [case-brief.md](case-brief.md) | Read the expected facts and research description first. |
| [linkedin.md](linkedin.md) | Assess the LinkedIn draft against the brief. |
| [informs.md](informs.md) | Assess the INFORMS Connect draft against the brief. |
| [email.md](email.md) | Assess the email draft, including its research claims. |
| [instructor-notes.md](instructor-notes.md) | Read the answer key only after your own assessment. |
| [README.md](README.md) | Explain this exercise and the order of use. |

Launch example mode from the [Agent Management guide](../README.md). Preserve these original drafts. Save corrected copies, checker reports, and reassessment in a new run record in the parent folder. This mode stays local and does not fill any accounts.
